# 吴延俊的个人主页

面向数据开发岗位求职的单页静态站，可直接部署到 GitHub Pages。

## 本地预览

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 内容原则

- 只展示 Obsidian 笔记中已经确认的事实。
- 未确认的工作年限、学历、项目规模、个人贡献边界和结果收益均明确标记为待补充。
- 页面用语参考 2026-06-12 整理的 38 份杭州数据岗位 JD，但不将招聘关键词冒充个人经验。

## 部署

将仓库推送到 GitHub，在仓库的 **Settings > Pages** 中选择从默认分支根目录部署。
