Hologres / SQL 优化 / 查询性能

Hologres 查询性能优化实践

针对部分报表查询慢、资源消耗高的问题，分析 SQL 写法、表结构、分布键和查询路径，优化高频查询体验。

  • 定位慢查询和高频访问场景。
  • 优化字段选择、过滤条件和关联方式。
  • 降低部分报表的等待时间和排查成本。
Flink / 实时指标 / 数据链路

实时指标链路建设

围绕实时业务监控场景，参与 Flink 实时任务开发和数据链路建设，让关键业务指标更快反馈到看板和运营侧。
